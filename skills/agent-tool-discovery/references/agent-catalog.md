# Agent discovery seed catalog

Use this catalog during inventory. It is a starting list, **not a popularity ranking, compatibility certification, installation request, or permanent path map**. Confirm current installed versions, local configuration overrides, and capabilities before writing anything. Products and paths change; dated third-party tables are only leads. Investigate other products found locally.

## International and open-source candidates

Codex, Claude Code, Gemini CLI, Google Antigravity, Cursor, Windsurf, GitHub Copilot (CLI and IDE variants), OpenCode, Cline, Roo Code, Grok Build, Kilo Code, Continue, Aider, Goose, OpenHands, OpenClaw, Hermes Agent.

Ordinary chat apps and cloud-only products need a capability check before inclusion in local repair.
